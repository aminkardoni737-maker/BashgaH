نصب روی اندروید:
1) همه فایل‌های این پوشه را روی یک میزبان HTTPS رایگان بگذار (مثلاً Netlify Drop یا GitHub Pages).
2) آدرس را در کروم گوشی باز کن.
3) از بخش تنظیمات، دکمه «افزودن به صفحه اصلی» را بزن (یا منوی سه‌نقطه کروم، گزینه «Install app»).
